**Why retrain:** `pth/BEVDet/bevdet_{sedan,suv,bus}.pth` were trained on a DIFFERENT codebase than the local `/BEVDet` repo — commit `39aa1b7` of `shdragron/BEVDet_CARLA` with an mmengine plugin `projects/bevdet_carla` (vanilla **BEVDet** / `LSSViewTransformer`, `CarlaCenterHead`, `CarlaNuScenesMetric`, batch 64x2, lr 8e-4). That commit was **force-pushed away**; the current repo (= local `/BEVDet`, dev3.0 `c9b3e58`, mmcv-1.x) is **BEVDetDepth** and can't load those weights (different framework era + view transformer). User chose (2026-06-03) to **retrain with the current dev3.0 BEVDetDepth** rather than recover the old code.

**Training (started 2026-06-03):** config `configs/bevdet/carla/bevdet-r50-carla.py` (BEVDetDepth-R50), all 3 vehicles sedan/suv/bus, 2-GPU DDP on B200 in env `bevdet-b200` (see [[bevdet-dev30-b200-env]]).
- Recipe (user-tuned for B200 util): `samples_per_gpu=64` (batch 128 = 64x2), `lr=8e-4`, `workers_per_gpu=16`, `persistent_workers=True`, 24 epochs, `evaluation=dict(interval=4)`. ~89GB/GPU, ~10h/vehicle (CPU/data-bound: dense DPT depth build).
- 6 classes (car/truck/bus/motorcycle/bicycle/pedestrian); GT = **visibility_token>=2** (num_pts ignored) — baked into ann_infos by the converter [[carla-geobev-dataset-layout]].
- **BEVDet-format pkls** (with `ann_infos`) are in `BEVDet/data/bevdet_infos/{veh}_infos_{train,val}.pkl` — generated by `tools/create_carla_data_bevdet.py`. Do NOT use `data/nuscenes/*.pkl` for BEVDet (those are BEVFormer-format, no ann_infos; clobbering breaks the BEVFormer benchmark). Launch overrides `data.{train,val,test}.ann_file` to data/bevdet_infos/.
- Depth GT is the dense **DPT** image (`sweeps/DPT-*`), NOT lidar (`CarlaDPTMultiViewDepth`); verified median DPT/lidar z = 0.998. Open question (ablation deferred): does DPT vs no-depth help/hurt NDS — would need a vanilla-BEVDet run to confirm.
- wandb: entity `Robust_Ex`, project `BEVDet-CARLA`, run name `carla_<veh>` (reuses the original project). sedan run: udcns5wu.
- Autonomy: `tools/train_carla_chain_suv_bus.sh` waits for sedan then trains suv+bus.

**Eval** (`CarlaNuScenesDataset._evaluate_single`): prints `[CARLA-EVAL] 6-class mAP/NDS`, restricts GT scenes to the pkl, visibility>=2 GT filter (num_pts override), `pts_bbox_NuScenes/` prefix. Next: after training, wire `run_bevdet.sh` into `bev_det_benchmark` (CTS/VP) + run eval with `--deterministic` and verify run-to-run identical.
